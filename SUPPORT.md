# Support

## Bugs and questions

Open a GitHub issue with: Keyway commit (or image tag), command or
endpoint, redacted config (never paste `KEYWAY_MASTER_KEY`, client
secrets, or `.env` contents), expected vs actual behavior, and relevant
logs with secrets removed.

Well-scoped issues get answered on a best-effort basis — there is no SLA
and no paid support tier. Pull requests fixing reported bugs are welcome
(see `CONTRIBUTING.md`); they are the fastest way to get a fix.

## Self-help order

1. `README.md` quickstart, Docker, and deployment sections.
2. `docs/operator-models.md` for hosting-model questions.
3. `keyway status`, server logs, and `connection test` output (redacted).

## Out of scope

Operating your deployment for you, IdP-side configuration beyond the
documented callback values, and incident response for live systems.
Managed single-tenant operation is offered per customer — see
`docs/operator-models.md`.
